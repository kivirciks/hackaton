# Руководство пользователя — локальный прототип «Коллектор»

## Вход и смысл экрана

Администратор запускает сервер из корня проекта; откройте `http://127.0.0.1:8080`. Демонстрационный вход: `dispatcher` / `demo`. Даты прогнозов исторические: последний исходный день в поставке — 30.06.2026. Показанная вероятность означает новый **тревожный сигнал** на следующие календарные сутки по паре объект/система, а не установленную поломку. Данные не отображают текущую обстановку в городе.

## Прогнозы и карточка

На странице «Прогнозы» строка над таблицей фильтрует объект, систему, статус, порог прогноза и текст. Таблица по умолчанию выводит активные сигналы первыми. «Активный сигнал» — тревога в последнем наблюдении; «Проверить» — прогноз выше выбранного моделью порога; «Нет свежих данных» и «Мало данных» — повод проверить передачу или покрытие; «Наблюдение» — нет перечисленных оснований для приоритета. Подсказки у заголовков объясняют вероятность и счетчик сигналов за 7 дней. Сводка по системам считает пары объект/система, а не число аварий.

Нажмите строку, чтобы открыть карточку. Проверьте дату, горизонт `valid_from`/`valid_to`, статус, основание, покрытие и историю. Шаг 1 «Зафиксировать решение» записывает действие и обоснование в журнал диспетчера. Шаг 2 «Подготовить заявку» независимо создает черновик: укажите оборудование, причину, приоритет и срок; затем отдельно подтвердите его. Подтверждение остается **только локальным**. По ID можно посмотреть локальную запись; поле внешнего статуса — явная заглушка. Номер оборудования и факт ремонта необходимо проверять в учетной системе заказчика.

## Остальные разделы

- «Схема»: условная SVG-группировка по родительским площадкам и номеру ПК. Красный — сигнал, оранжевый — прогноз выше порога, зеленый — наблюдение, серый — мало/нет данных. Цвет не подтверждает поломку; координаты и расстояния не являются географическими. Доступны фильтры по системе и состоянию.
- «Оборудование»: поиск объекта в дереве, сворачивание веток, просмотр и поиск каналов выбранного объекта. При наличии права можно добавить локальную запись; исходный реестр не меняется.
- «Оповещения»: появляются при историческом воспроизведении; кнопка просмотра отмечает ознакомление, не завершение ремонта.
- «Отчеты»: выберите один из пяти видов — управленческий, прогнозы, оповещения и решения, качество данных, журнал действий. Укажите период не более 367 дней и применимые фильтры. Экран, Excel и PDF строятся из одного среза. Для прогнозного/качественного отчета даты периода не создают новый исторический прогноз: показывается включенный снимок; для действий период относится ко времени записи.

Страница «Поступление данных» и «Роли и доступ» доступны только администратору. Созданная им роль может иметь иной набор страниц. Вопрос о недоступной странице решается через администратора, не через переключатель в браузере.
